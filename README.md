# چرخ انتخاب | Name Wheel

A simple bilingual name wheel with Persian sample names. Add or remove names,
switch between فارسی and English, then spin to make a random pick.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deploy to GitHub Pages

The GitHub Actions workflow builds the app and deploys it to GitHub Pages when
changes are pushed to `main`. In the repository settings, set **Pages → Build
and deployment → Source** to **GitHub Actions**.
